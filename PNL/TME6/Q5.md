## **Task 5: Using `kref` for `task_sample`**

### **Step 1: Extend `task_sample` with `kref`**

### **Step 2: Implement a release function**

This is called when the reference count drops to 0. Since you are using a **mempool**, the release function should free the object back to the pool:

```c
void sample_release(struct kref *ref) {
    struct task_sample *sample = container_of(ref, struct task_sample, refcount);
    mempool_free(sample, sample_pool);
}
```

### **Step 3: Initialize the reference counter on allocation**

When you allocate a new sample (in `save_sample()`), initialize the refcount to 1:

```c
struct task_sample *save_sample(void) {
    struct task_sample *my_sample = mempool_alloc(sample_pool, GFP_KERNEL);
    if (!my_sample) {
        printk(KERN_ERR "Memory allocation failed\n");
        return NULL;
    }

    kref_init(&my_sample->refcount);  // <-- initialize reference

    if (!get_sample(&monitor, my_sample)) {
        kref_put(&my_sample->refcount, sample_release);
        return NULL;
    }

    mutex_lock(&monitor.mtx);
    list_add(&my_sample->list, &monitor.head);
    monitor.count++;
    mutex_unlock(&monitor.mtx);

    return my_sample;  // <-- return reference to caller
}
```

### **Step 4: Increment and decrement references as needed**

If a caller wants to hold onto a sample **without holding the mutex**, increment the reference:

```c
struct task_sample *sample = save_sample();
if (!sample) return;

// Hold a reference
kref_get(&sample->refcount);

// Print sample info without holding the list mutex
printk(KERN_INFO "utime=%llu stime=%llu\n",
       (unsigned long long)sample->utime,
       (unsigned long long)sample->stime);

// Release reference
kref_put(&sample->refcount, sample_release);
```

* **Key idea:**
  `kref_get()` increments the reference, and `kref_put()` decrements it. When the last reference is gone, `sample_release()` is called automatically.

### **Step 5: Adjust shrinker**

In the shrinker, when you remove samples from the list:

```c
list_for_each_entry_safe(smp, tmp, &monitor.head, list) {
    list_del(&smp->list);
    monitor.count--;
    kref_put(&smp->refcount, sample_release);  // <-- drop reference from list
    freed++;
}
```

* Removing a sample from the list **does not immediately free it** if another part of the code still holds a reference.

### **Step 6: Answering Question 3**

> How many references should you have for a sample just before it is printed by the kthread? Why?

* **Answer:** **1 reference per user of the sample.**

* Reason: The `kthread` calling `print_sample()` must hold a reference to ensure the sample is not freed while it is being printed. After printing, it releases the reference.

* For example:

  * When allocated: refcount = 1 (owned by list)
  * Kthread prints: calls `kref_get()` → refcount = 2
  * After printing: calls `kref_put()` → refcount = 1 (list still owns it)
